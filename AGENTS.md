# Agent instructions

## Contribution rules

Follow CONTRIBUTING.md, AI_POLICY.md, and the repository issue and PR templates.
Chainlink is retired. Use the canonical GitHub issue and its existing Linear
mirror; never create Chainlink issues or sessions. AI disclosure and model
attribution are optional. Sign commits, retain required DCO sign-off, and verify
GitHub marks each commit Verified. Publish agent PRs as comail-agents[bot].

Use native GitHub stacks for dependent same-repository PRs and verify their REST
stack metadata. Upload PR screenshots and recordings as native attachments;
never commit review media. Preserve product assets and historical review links.
Write comments about current contracts and reasons; remove obsolete narration
when editing an area. Preserve security boundaries and generated/license notices.
